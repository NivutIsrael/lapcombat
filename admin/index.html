כניסת מנהלים

רק מנהלים מאושרים: משתמשי GitHub שבעל האתר נתן להם הרשאת כתיבה לאתר. הכניסה נבדקת מול GitHub.

איך מקבלים מפתח גישה?
  1. בעל האתר מאשר אותך: ב-GitHub, במאגר REPO, ב-Settings ← Collaborators.
  2. ב-GitHub: Settings ← Developer settings ← Personal access tokens. בעל המאגר: Fine-grained token עם גישה רק למאגרים REPO ו-DATAREPO, והרשאות Contents: Read and write ו-Actions: Read (בשביל העלאת קבצים ומעקב אחרי הבנייה). מנהל שותף: Token (classic) עם ההרשאה public_repo בלבד. כדאי לתת תוקף קצר.
  3. מדביקים כאן. המפתח נשמר רק בלשונית הזו ונמחק כשסוגרים אותה או לוחצים ״יציאה״. הוא נשלח רק ל-GitHub.

תחרויות באתר

הקישור לתוצאות החיות של המארגנים במולקה (Mulka2 Cloud). השמירה מעדכנת את האתר תוך כדקה, בלי לבנות דוחות מחדש.

תחרות שעוד לא באתר

תחרות קרובה או שמתקיימת עכשיו: היא תופיע בראש האתר עם כפתור לתוצאות החיות, והניתוח יתחבר אליה אחרי התחרות.

אם כבר יש במחשב תיקייה לתחרות, כתבו את שם התיקייה באותיות קטנות, כדי שהניתוח יתחבר לאותה תחרות.

העלאת קבצי תחרות

הקבצים נשמרים במאגר הפרטי, ו-GitHub מריץ עליהם את כל הניתוח – אותו קוד כמו במחשב – ומפרסם את האתר, בדרך כלל תוך 3–5 דקות. קובץ בשם שכבר קיים בתחרות מחליף אותו.

דוחות זמני הביניים (.htm), קובצי LapCombat של הקטגוריות והמסלולים (.lxm), המסלולים (IOF .xml), מפת OCAD (.ocd), ורשימת זינוק (קובץ HTML ששמו כולל start או זינוק). לפני התחרות אפשר להעלות רק את רשימת הזינוק – היא תופיע באתר מיד. מרשימת הזינוק נלקחים רק שעה, שם, קטגוריה, מועדון ומסלול – לא טלפונים ולא מספרי SI.
